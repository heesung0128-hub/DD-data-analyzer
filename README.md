# DD Data Analyzer (데이터 분석기)

수학·과학 탐구 활동에서 두 변수 사이의 관계를 함수로 나타내 보는 웹 앱입니다.
서버 없이 브라우저에서만 동작하며, 입력한 데이터는 외부로 전송되지 않습니다.

## 주요 기능

| 단계 | 기능 |
|---|---|
| 1. 데이터 입력 | CSV, 엑셀(.xlsx/.xls), 표 붙여넣기, 연습용 샘플 4종 |
| 2. 함수 모델링 | 선형 · 지수 · 로그 · 2~4차 다항 추세선, 결정계수(R²), p-value(선형 기준), 잔차 그래프, 모델 자동 추천(조정된 R² 비교), 요약 보고서(txt) 다운로드 |
| 3. 데이터 예측 | 구한 추세선에 독립변수 값을 넣어 종속변수 예측 |
| 4. 적분 탐구 | 구간 [a, b]의 정적분 계산 및 넓이 시각화 (다항함수는 정확한 값, 지수·로그는 심프슨 수치적분) |

## 사용 방법

1. `index.html`을 브라우저에서 엽니다. (인터넷 연결 필요: 아래 외부 라이브러리를 CDN으로 불러옵니다.)
2. 첫 줄에 변수 이름, 둘째 줄부터 숫자 데이터를 넣은 파일을 올리거나 샘플을 선택합니다.
3. 독립변수(X)와 종속변수(Y), 추세선 모델을 고르고 분석을 시작합니다.

CSV에서 한글이 깨지면 화면의 인코딩 선택(EUC-KR / UTF-8)을 바꿔 보세요.

## 참고

- 샘플 데이터는 연습용 **가상 데이터**입니다.
- R²가 높다는 것은 두 변수가 함께 변한다는 뜻이며, 원인까지 보장하지는 않습니다.
- 데이터 범위 밖의 예측값은 참고용으로만 활용하세요.

## 파일 구성

- `index.html` : 화면 구조
- `style.css` : 스타일
- `script.js` : 데이터 처리, 회귀 분석, 그래프, 적분 계산

## 사용한 외부 라이브러리 (CDN)

PapaParse 5.4.1, SheetJS(xlsx) 0.18.5, jStat 1.9.6, regression-js 2.0.1, Plotly.js 2.32.0, KaTeX 0.16.9, Font Awesome 6.4.0, Google Fonts(Inter, Outfit, Noto Sans KR)

각 라이브러리의 라이선스는 해당 프로젝트를 따릅니다.
