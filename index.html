Step 2. 분석 설정

숫자형 데이터 부족

상관관계를 분석하려면 숫자로 된 열이 최소 2개 이상 필요합니다. 데이터 입력을 다시 확인해주세요.

설정을 완료했다면 분석을 시작하세요.

분석 결과 레포트

설명력 (결정계수 R²)

(참고용) 0.05 미만일 경우 뚜렷한 선형적 관계가 입증됨

추세선 방정식

잔차(Residual) 그래프

실제값과 예측값의 차이(오차)를 보여줍니다. 점들이 0을 기준으로 특별한 규칙 없이 흩어져 있을수록 모델이 데이터를 잘 설명하는 것입니다.

도출된 수학 모델을 바탕으로 데이터를 예측해볼 수 있습니다.

Step 3. 데이터 예측하기

가설 검증(Step 2)에서 찾은 추세선 수학 모델을 바탕으로 독립변수 값을 입력하면 종속변수의 변화를 예측해 줍니다.

추세선 방정식
예측 결과
입력한 독립변수 값이 0일 때,
예측되는 종속변수 값은 0 입니다.
